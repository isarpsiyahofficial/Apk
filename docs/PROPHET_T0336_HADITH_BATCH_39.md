# T0336 Hadith Batch 39 — İshak ve Ya‘kûb

This batch advances only the `hadith` dimension for İshak and Ya‘kûb. Both claims use **Sahih al-Bukhari 3390** as an exact `REFERENCE-ONLY` locator, with separate internal provenance IDs so semantic ownership remains auditable.

## Why the shared report is admissible

Bukhârî 3390 is not an incidental name list. The hadith directly states the ordered lineage Yûsuf → Ya‘kûb → İshak → İbrâhim in a prophetic-honour proposition. For that limited hadith dimension, the report directly attests both Ya‘kûb and İshak. This mirrors the existing T0336 policy that one sahih report may support multiple biography owners only when it makes a direct proposition about each owner; natural contextual mentions alone remain insufficient.

TDV's *Ya‘kûb* article explicitly states that Ya‘kûb is mentioned as a prophet and noble person in hadith and cites Bukhârî, Enbiyâ 14 and 19. TDV's *Yûsuf* article independently describes the same İbrâhim → İshak → Ya‘kûb → Yûsuf prophetic succession and cites Bukhârî, Enbiyâ 19.

## Fail-closed boundaries

- `biographyProphetId` and `subjectProphetId` must match the intended owner.
- Source id/title/class/license/locator must match exactly.
- These hadith claims do not add or replace `familyLineage`, `chronology`, `geography`, or `historicalDate` evidence.
- A Yûsuf-owned claim cannot be relabelled as İshak/Ya‘kûb merely because the names occur in the same report; each admitted claim has an explicit direct-proposition rationale and distinct source ID.

## Remaining hadith gaps

After batch 39, five canonical prophets remain explicit unresolved for the hadith dimension: `hud`, `shuayb`, `dhul-kifl`, `ilyas`, `alyasa`. No claim should be promoted for them without a source-reviewed hadith that directly supports biography ownership.
